## 2. 已确认的安全设计

- 全局 DTO 白名单校验、类型转换和未知字段拒绝已启用。
- 管理员密码使用 `scrypt`、随机盐和常量时间比较。
- 管理员会话与外部身份会话使用高强度随机 Token，数据库只保存 SHA-256 哈希。
- 管理员 Cookie 和外部身份 Cookie 使用 HttpOnly、SameSite，并可在 HTTPS 下强制 Secure。
- 管理员会话绑定稳定设备标识；同设备重复登录撤销旧会话。
- 登录、后台入口、公开提交、身份恢复和查询接口均有限流。
- 全新安装默认不启用后台安全入口，便于管理员完成首次配置；管理员手动设置入口后使用 HMAC 签名 Cookie，入口变化会让旧授权失效。生产验收清单要求首次登录后启用入口。
- 请求 Host、转发 Host 和客户端 IP 只在可信代理条件下使用。
- 域名白名单支持精确域名和受控通配域名；IP 与本机回环按现行规则处理。
- 错误路径、缺失/失效公开 Token 不跳转管理员登录。
- 支付宝、银行卡和返利凭证使用 AES-256-GCM；普通接口和日志不返回密文或明文 Token。
- ApiZero API Key 使用 AES-256-GCM 保存，只在 API 服务发起请求时作为 Bearer 凭证使用；查询审计只记录运单号、承运商、状态和轨迹数量，不记录 API Key 或手机号后四位。
- 完整及分类备份使用 gzip + AES-256-GCM，恢复要求管理员密码和 RESTORE 确认词；完整恢复撤销管理员及公开身份会话，分类恢复只合并所选数据且不执行整库清空，系统与管理员分类恢复会撤销会话。
- 富文本只允许受控标签、样式和属性，公开页展示服务端清洗后的内容。
- 订单删除使用软删除，关键登录、配置、业务和维护操作写入审计。
- `.env`、本机数据库、备份、附件和日志目录均被版本忽略规则覆盖。

## 4. 当前仍需完善

### P0：系统更新

系统更新仍未实现。它必须包含升级前备份、迁移、健康检查和失败回滚，见 `docs/roadmap.md`。完整及分类数据备份/恢复能力已在系统设置“功能扩展”中接通。

### P1：生产服务维护桥接

本机监视模式可真实重启 Web/API；正式环境由外部服务管理器托管时，系统会显示“外部托管”。后续更新模块应通过独立维护代理或服务管理器桥接实现生产环境受控重启，不能让业务 API 直接覆盖自身文件。

### P1：自动化安全回归

建议补充：

- 后台入口、域名白名单和公开链接路由矩阵测试。
- 可信代理、伪造 `X-Forwarded-For` 和限流测试。
- 管理员 Cookie、Secure/SameSite 和跨域部署测试。
- 富文本恶意 URI、标签和样式测试。
- 公开身份识别码枚举、昵称冲突和跨设备恢复测试。
- 关键页面 360px/390px/768px/桌面亮暗主题截图回归。

### P1：生产安全头

正式 Web 入口需要配置 HTTPS、`nosniff`、Referrer Policy、Frame Policy 和 Permissions Policy；当前推荐配置已写入 `docs/deployment.md`。上线后再根据实际第三方资源制定 CSP，避免直接套用导致 Element Plus、二维码或接口请求被误拦截。

### P2：前端分包性能

当前生产构建可以正常完成，但主客户端包约 1.94 MB，gzip 后约 591 KB，构建工具会提示大包警告。正式外网部署前建议按 Element Plus、VXE Table 和业务模块拆分公共包，并继续保持路由懒加载，降低微信内置浏览器的首次加载时间。
