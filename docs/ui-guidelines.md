# 系统 UI 规范

> 本文记录当前最终视觉规则。实现基准是 `apps/web/src/style.css`；后续页面先复用现有变量和组件，再补充本文件，不回看旧修改过程。

## 1. 视觉方向

- 整体风格：轻量玻璃感、柔和渐变、圆角、低饱和阴影、紧凑信息密度。
- 管理后台：优先在一屏展示更多有效信息，避免无意义的大面积留白和纵向堆叠。
- 公开页面：保持同一视觉语言，但加大触控区域、正文可读性和移动端间距。
- 亮色与暗色使用同一层级关系；暗色不是简单反色，固定列、弹窗、输入框和提示卡都必须使用暗色变量。
- 新功能不得建立独立视觉体系，也不得恢复已取消的旧样式。

## 2. 全局设计变量

变量统一定义在 `apps/web/src/style.css`。

| 用途       | 变量               | 亮色      | 暗色      |
| ---------- | ------------------ | --------- | --------- |
| 主色       | `--app-primary`    | `#3b82f6` | 同亮色    |
| 成功       | `--app-success`    | `#10b981` | 同亮色    |
| 警告       | `--app-warning`    | `#f59e0b` | 同亮色    |
| 危险       | `--app-danger`     | `#ef4444` | 同亮色    |
| 标题       | `--app-heading`    | `#0f172a` | `#f8fafc` |
| 正文       | `--app-text`       | `#334155` | `#cbd5e1` |
| 辅助文字   | `--app-muted`      | `#64748b` | `#94a3b8` |
| 页面背景   | `--app-background` | `#eef3f9` | `#0b1220` |
| 半透明卡片 | `--app-card`       | 白色 78%  | 深色 72%  |
| 实色卡片   | `--app-card-solid` | `#ffffff` | `#111827` |
| 控件背景   | `--app-control`    | 白色 82%  | 深灰 74%  |
| 统一边框   | `--app-border`     | 灰蓝 22%  | 灰蓝 17%  |
| 悬停层     | `--app-hover`      | 灰蓝 10%  | 灰蓝 10%  |

规则：

- 页面业务样式不得写死白色背景、黑色正文或浅灰边框。
- 只有品牌标识文字等明确需要纯白的元素可直接使用 `#fff`。
- 状态色的浅背景使用 `color-mix()` 与主题变量生成。
- 阴影优先使用 `--app-shadow-sm` 和 `--app-shadow`。

## 3. 字体与信息层级

- 字体栈：`Inter`、`PingFang SC`、`Microsoft YaHei`、系统字体。
- 全局正文基准：17px；Element Plus 基准：15px；VXE Table 基准：15px。
- 页面主标题：24px，移动端 22px。
- 页面说明：14px；卡片辅助说明通常 12–13px。
- 表格表头：13px、600 字重；表格正文保持高密度，不额外加粗。
- 左侧菜单、折叠菜单和订单列表不得跟随公开页面一起放大。
- 在线报单、回款登记和订单查询的关键正文可比后台高密度区域大 2–3px，但同页层级必须一致。
- 金额使用 `.money` 或等价样式，启用等宽数字 `font-variant-numeric: tabular-nums`。

## 4. 圆角、边框与间距

- 主卡片 `.surface-card`：18px 圆角，1px 主题边框；手机端 16px。
- 选择卡 `.card-choice`：15px 圆角。
- 输入框、选择器、日期和数字框：11px 圆角。
- 普通按钮：10px 圆角；标签和需要强调的轻操作可使用胶囊圆角。
- 弹窗：22px 圆角，标题、正文、底部分区使用主题边框。
- 页面纵向间距：`.page-shell` 默认 14px。
- 管理后台内容区：桌面端约 20px/22px，窄屏收紧到 12px/10px。
- 小模块按内容决定宽度，优先采用 2–4 列自适应网格，禁止为了占满整行把简单开关或短文本卡拉得过宽。
- 页面和 Grid/Flex 子项默认允许收缩：需要横向滚动的标签或表格由自身容器承接滚动，父级补充 `min-width: 0`，不得依赖页面级 `overflow-x: clip` 掩盖内容被撑宽的问题。

推荐网格：

```css
display: grid;
grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
gap: 10px;
```

有明确最大宽度的输入模块使用 `minmax(280px, 520px)` 一类约束，并 `justify-content: start`。

## 5. 卡片选择

- 平台、品类、支付方式、状态、返利接口、字段权限等统一使用 `.card-choice`。
- 选中态只通过边框、浅色背景和内阴影表达，不显示右上角对勾、角标三角或额外勾选图标。
- 卡片内容只需容纳文字和必要图标，不为短标签保留大面积空白。
- 横向选择优先同一行显示；手机宽度不足时自然换行。
- 状态按钮文字必须水平、垂直居中，所有同组卡片高度一致。
- 禁用态降低透明度并使用 `not-allowed`，仍需保留可读文字。

## 6. 输入与表单

- 所有 `el-input-number` 隐藏左右加减控件，同时隐藏浏览器原生微调按钮；新页面不得单独恢复。
- 金额允许整数或最多两位小数，不设置 10 元步进等业务外限制。
- 表单按语义分组，短开关放在“开关类”，文本和地址放在“内容类”，访问规则放在“规则类”。
- 同一设置页面只有一个总保存按钮；独立即时操作可以有单独按钮，但不得出现重复保存入口。
- 必填、只读、后台专用均由后台配置或真实业务规则控制，不写死没有依据的锁定状态。
- 输入说明紧贴对应控件，不在页面其他位置重复说明。
- 富文本编辑与公开展示必须保留加粗、斜体、下划线、字号和颜色，并由服务端白名单过滤。

## 7. 按钮与操作组

- 行内操作使用低饱和、圆角、紧凑操作组；复制、编辑、删除、载入等同类按钮视觉一致。
- 危险操作使用危险色，但不使用高饱和整块红底；执行前按风险增加二次确认。
- 图标尺寸、文字基线和按钮高度在同一操作组内保持一致。
- 主操作使用主色；次操作优先普通或文字按钮；成功色只用于明确成功行为。
- 小屏下重要按钮可占满一行，桌面端不无意义拉伸。
- 未接通真实 API、权限、持久化和错误反馈的功能不显示占位按钮；确定暂缓的功能等完整实现后再加入界面。

## 8. 表格

- Element Plus 与 VXE Table 必须共用主题变量。
- 表头背景使用实色主题变量；固定操作列表头与相邻表头完全同色。
- 固定列正文使用 `--app-table-fixed-row`，条纹、悬停分别使用对应实色变量。
- 关闭固定列边缘伪元素和阴影，禁止白边、重影、透色或后一列表头叠影。
- 选中订单时整行、左右固定列同步高亮；双向结清行仍可选择。
- 少量数据完整展开，超过可视高度后再启用表格内部滚动。
- 复制为图片时使用紧凑蓝色表头，降低表头高度，移除排序/筛选箭头和交互控件，只保留用户选择的字段和值。
- 运单号列预留后续快递查询操作空间；平台运单号和寄件运单号当前宽度基准 175px。
- 运单号存在时在文本右侧使用统一低饱和圆角小图标触发物流查询；无运单号不渲染空按钮，查询结果使用主题一致的轨迹时间线。

## 9. 页面导航与设置页

- 基础设置和系统设置的分类导航使用圆角分段式标签，选中态为浅主色背景、边框和轻阴影。
- 标签允许横向滚动，手机端不挤压成多行错位。
- 系统设置按“面板配置、运行状态、服务维护、安全管理、操作日志、功能扩展”分类。
- 面板配置按“界面显示、后台访问、域名首页”等语义分组；组内一项功能独占一行。桌面端使用紧凑相邻列，说明列保持窄宽度，控件紧跟其后且不得推到整行最右侧；剩余留白放在控件之后。手机端上下排列。避免分类卡片内再次堆叠功能卡片，并只保留一个总保存按钮。
- 运行状态的每一条服务信息独立成行或卡片，禁止多行内容叠在同一网格单元。

## 10. 公开页面与移动端

- 公开页面最大内容宽度居中，背景与后台使用同源渐变和主题变量。
- 识别码组件在在线报单与订单查询中复用同一视觉结构。
- 在线报单的方案信息、填写说明和表单字段分别使用圆角分区，不让富文本裸露在页面背景上。
- 支付方式三卡片优先左中右排列；窄屏再自动换行。
- 触控目标建议不小于 40px；页面禁止横向溢出。
- 断点基准：900px 收紧后台侧栏，768px/760px 转单列或横向滚动，560px 使用移动抽屉和全宽关键按钮。
- 在 360px、390px、768px、桌面宽度分别检查布局；微信内置浏览器需检查长文本、软键盘和安全区。

## 11. 暗色主题验收

- 页面、卡片、弹窗、输入框、表格固定列和悬浮层没有纯白边或纯白背景泄漏。
- 标题、正文、辅助文字层级清晰，不出现深底白字过亮或浅灰字不可读。
- 公式预览、利润预览、状态卡和富文本说明全部使用主题变量。
- Element Plus 的 overlay、table、dialog、select、tag 与 VXE Table 切换主题后同步刷新。

## 12. 新页面验收清单

- [ ] 复用 `.page-shell`、`.surface-card`、`.card-choice` 和主题变量。
- [ ] 亮色、暗色均检查，无硬编码主题外边框。
- [ ] 桌面布局紧凑，简单小模块未被拉满整行。
- [ ] 选择卡无右上角对勾。
- [ ] 数字输入无加减按钮，金额支持两位小数。
- [ ] 固定列无白边、重影和透色。
- [ ] 操作按钮与现有低饱和圆角操作组一致。
- [ ] 手机 360px 宽度无横向滚动、遮挡或文字叠加。
- [ ] 功能接通真实状态、加载、空数据、错误和权限反馈。
