# 当前订单与业务字段字典

> 只记录现行字段含义。数据库最终结构以 `apps/api/prisma/schema.prisma` 为准。

## 1. 订单核心字段

| 页面名称       | 数据字段                    | 类型          | 当前含义                                        |
| -------------- | --------------------------- | ------------- | ----------------------------------------------- |
| 序号           | `serialNo`                  | 自动整数      | 数据库连续业务序号，不是商品 SN                 |
| 下单时间       | `orderedAt`                 | 时间          | 按 Asia/Shanghai 展示和筛选                     |
| 下单平台       | `platformId`                | 关联          | 关联启用的平台字典                              |
| 下单人         | `submitterId`               | 关联          | 下单账号与下单人统一使用微信昵称                |
| 品类           | `categoryId`                | 可空关联      | 订单实际品类；可由公开表单或管理员补充          |
| 商品/方案*数量 | `productNameSnapshot`       | 多行文本      | 一行可写一个商品/方案和数量，不存在独立数量字段 |
| 平台订单号     | `platformOrderNo`           | 可空文本      | 同平台内唯一时用于去重                          |
| 平台运单号     | `inboundTrackingNo`         | 可空文本      | 平台发货到管理员/指定地址的运单号               |
| 下单地址       | `purchaseAddress`           | 可空长文本    | 平台订单使用的地址，不是后台专用字段            |
| 收货佬         | `customerId`                | 可空关联      | 商品寄出的接收方与管理员应收对象                |
| 寄件运单号     | `Shipment.trackingNo`       | 可空文本      | 管理员寄出包裹的运单号；后续支持物流查询        |
| 支付方式       | `fundingType`               | 枚举          | 自己付、代付、其他；不是微信/支付宝结算渠道     |
| 下单金额       | `orderAmount`               | Decimal(18,2) | 订单登记金额                                    |
| 支付优惠       | `paymentDiscountAmount`     | Decimal(18,2) | 计入当前利润公式的优惠收益                      |
| 结算金额       | `submitterSettlementAmount` | Decimal(18,2) | 应给下单人的金额                                |
| 回款金额       | `customerReceivedAmount`    | Decimal(18,2) | 收货佬给管理员的回款金额                        |
| 原始扫码金额   | `scanAmount`                | Decimal(18,2) | 管理员录入的原始扫码金额                        |
| 实际扫码返利   | `platformRebateAmount`      | Decimal(18,2) | 原始扫码金额 × 0.9，只读计算                    |
| 备注           | `notes`                     | 可空长文本    | 业务补充说明                                    |
| 修改说明       | 审计记录                    | 文本          | 非空修改按时间进入操作日志，不与普通备注混用    |

## 2. 状态

| 页面名称     | 数据字段                    | 当前值                       |
| ------------ | --------------------------- | ---------------------------- |
| 审核状态     | `reviewStatus`              | 草稿、待确认、已通过、已驳回 |
| 寄件状态     | `shipmentStatus`            | 未寄出、已寄出、已签收、异常 |
| 回款状态     | `receivableStatus`          | 未回款、已回款、异常         |
| 结算状态     | `submitterSettlementStatus` | 未结算、已结算、异常         |
| 订单有效状态 | `status` + `deletedAt`      | 有效、取消/软删除            |

寄件、回款和结算互相独立。批量已结算不得修改回款状态，批量已回款不得修改结算状态。

## 3. 利润字段

当前默认公式：

```text
利润 = 回款金额 - 结算金额 + 支付优惠 + 实际扫码返利
```

- `expectedProfit`：按当前金额计算的预估结果。
- `settledProfit`：收货佬已回款后显示的已结算结果，否则为 0。
- `profitRuleId`、`profitRuleVersion`、`profitRuleSnapshot`：保存订单使用的规则版本。
- 当前规则选择器只允许回款金额、结算金额、支付优惠、下单金额、扫码返利和固定金额。
- 数据库中为后续流水预留的其他金额列不属于当前 UI 计算项，不应出现在利润规则下拉框。

## 4. 下单人与回款方式

### Submitter

| 字段                | 含义                                   |
| ------------------- | -------------------------------------- |
| `name` / `nickname` | 当前使用的微信昵称                     |
| `code`              | 下单人唯一识别码；后台手工建立时可为空 |
| `status`            | 档案状态                               |
| `notes`             | 管理员备注                             |

### PayoutMethod

| 类型     | 必要资料                 |
| -------- | ------------------------ |
| 微信转账 | 微信昵称                 |
| 支付宝   | 支付宝账号               |
| 银行卡   | 真实姓名、银行、银行卡号 |

支付宝账号和银行卡号写入 `accountValueEncrypted`，使用 AES-256-GCM；管理列表只返回脱敏值。公开提交先为 `PENDING`，管理员确认后为 `ACTIVE` 并锁定外部变更。

## 5. 在线报单

- `OrderScheme.name`：方案名称，只读展示。
- `OrderScheme.productName`：多行方案内容，只读展示。
- `OrderScheme.description`：方案说明，只读展示。
- `ShareForm.title`：公开页标题，默认“在线报单系统”。
- `ShareForm.description`：富文本填写说明。
- `ShareForm.fieldConfig`：订单字段可见、可填、必填、默认值与结算金额模式。
- `ShareForm.publicToken`：固定公开链接 Token。
- `allowEditBeforeApproval` / `allowDeleteBeforeApproval`：确认前权限。

方案名称、方案内容和方案说明不写入订单列表。订单的商品、品类和金额来自下单人实际填写或管理员补充。

## 6. 订单查询可见字段

订单查询配置从当前有效订单字段和启用扩展字段动态生成。服务端只返回管理员开放的字段，默认业务范围包括：

```text
下单时间
商品/方案*数量
平台运单号
寄件运单号
下单金额
结算金额
结算状态
```

查询页不返回利润、内部审计、完整账号、后台 Token 或编辑权限。

## 7. 自定义字段

`CustomFieldDefinition` 定义名称、类型、排序、是否显示、是否筛选和外部权限；`OrderCustomFieldValue` 保存订单值。

- 金额、日期、布尔、多选等按类型展示和校验。
- 参与资金计算、状态或高频筛选的字段应升级为正式数据库列。
- 普通补充信息可继续使用扩展字段。
- 订单查询、列设置和在线报单权限必须从启用定义动态加载。

## 8. 导入兼容

WPS/Excel 导入后续按本字典映射：

- 旧数量列合并进“商品/方案*数量”。
- 下单账号按微信昵称匹配或创建下单人。
- 平台和品类必须匹配当前启用字典。
- 每行独立校验，保留导入批次和原始错误信息。
- 导出功能当前暂缓。
